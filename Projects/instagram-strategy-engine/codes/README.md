# Codes

This directory contains all executable source code, scripts, modules, and utilities for the Instagram Automation project.

## Suggested Organization
- `src/` or sub-folders:
  - `api/` — Instagram Graph API / Meta API clients
  - `agents_runtime/` — Execution runners connecting agent definitions to code logic
  - `generators/` — Media, image, and text generation scripts
  - `utils/` — Helper functions, config loaders, formatters
- `requirements.txt` / `package.json` — Dependency management
