# Agents Directory

This directory houses all specialized agents created for this project.

## Structure Per Agent
Each agent has its own folder containing two mandatory files:
- `information.md` — The agent's role, persona, responsibilities, context, inputs, and outputs.
- `skills.md` — The skills, capabilities, toolsets, and rules assigned to the agent.
