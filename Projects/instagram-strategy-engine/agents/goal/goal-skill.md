# Goal & Target-Setting Skill

The target-setting layer — turn business outcomes into a measurable cascade with one North Star per channel, benchmark-set targets, and action thresholds. This skill sets the win conditions; `analytics-and-reporting` measures against them.

---

## The POV: Goals, Not Wishes
*"Grow our following,"* *"go viral,"* *"do better on Instagram"* are wishes — unmeasurable, unowned, and disconnected from the business. Build a cascade instead:

$$\text{Business Goal} \longrightarrow \text{SMART Objective} \longrightarrow \text{KPI} \longrightarrow \text{Supporting Metrics}$$

With one North Star per channel tied to its real job, a target from your own benchmark (achievable yet ambitious), a 3–5 cap for focus, and thresholds that trigger action. A KPI must be controllable, non-vanity, and mapped to an outcome — and a well-set one (a follower target paired with an engagement floor) prevents gaming.

## The Framework: NORTH
*(In-depth guide: [references/the-north-framework.md](file:///c:/Users/crypt/OneDrive/Desktop/TINTIN/Instagram%20automation/agents/goal/references/the-north-framework.md))*

- **N — Name the business goal**: Anchor every social goal to a real outcome (awareness / leads / sales / retention); if it doesn't ladder up, cut it.
- **O — One North Star per channel**: The single win-condition metric (awareness $\rightarrow$ reach; consideration $\rightarrow$ CTR; conversion $\rightarrow$ CVR) + 1–2 supporting.
- **R — Render it SMART**: Specific, Measurable, Achievable, Relevant, Time-bound — a number + a deadline + a method.
- **T — Target from benchmarks**: Set the number from your baseline / comparable benchmarks (no data $\rightarrow$ a learning goal first); leading + lagging; only controllable KPIs.
- **H — Hold to 3–5 + set triggers**: Cap KPIs/objectives at 3–5; action thresholds (*"if X holds but Y drops $\rightarrow$ do Z"*); review weekly/monthly/quarterly; hand to `analytics-and-reporting`.

## Honest Scope (Never Violate)
1. **Sets, doesn't measure** — Measuring progress is `analytics-and-reporting` (native analytics; WoopSocial has none). This skill defines targets/North Stars/thresholds, then hands off.
2. **Targets from real benchmarks** — No fabricated baselines; no data $\rightarrow$ a learning goal first; comparable benchmarks are provisional/flagged.
3. **Controllable, non-vanity, outcome-mapped KPIs only.** Pair growth with a quality guardrail — a well-set KPI prevents gaming (no follower-buying/engagement pods).
4. **Realistic, not hype** — Achievable yet ambitious; flag impossible asks. If a target is missed $\rightarrow$ pivot tactics first, don't move the goalposts or fudge numbers.

## Definition of Done
A completed target-setting artifact includes:
- [ ] A cascade per goal (business outcome $\rightarrow$ SMART objective with number + deadline + method $\rightarrow$ one North Star per channel + 1–2 supporting).
- [ ] Targets set from real baselines/benchmarks (or a learning goal if none), achievable yet ambitious, with a quality guardrail.
- [ ] Capped at 3–5 with action thresholds and a weekly/monthly/quarterly review cadence.
- [ ] Controllable, non-vanity, outcome-mapped KPIs.
- [ ] Handed off to `analytics-and-reporting` to measure.
- [ ] Nothing fabricated, correctly distinguished from analytics, strategy, and experimentation.
