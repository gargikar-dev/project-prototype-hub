# Social Media Platform Profile Specifications

Technical constraints, character limits, and interface rules across primary platforms.

---

## 1. Instagram Specifications

- **Handle (`@username`)**: Max 30 characters (letters, numbers, periods, underscores).
- **Name Field**: Max 64 characters (fully indexed for Instagram Search / SEO).
- **Bio**: Max 150 characters. Supports line breaks, emojis, and hashtags.
- **Link**: Supports multiple links or a native external URL with customizable link title.
- **Profile Photo**: 320 x 320 px minimum (displays as circle). High contrast recommended.
- **Pinned Grid Posts**: Up to 3 pinned reels/posts at the top of the grid.
- **Highlights**: Unlimited count, but only the first 4–5 are visible above the fold without horizontal scrolling.

---

## 2. LinkedIn Specifications

- **Profile Headline (Personal)**: Max 220 characters. Highly indexed in LinkedIn search.
- **About / Summary Section**: Max 2,600 characters. First 3 lines (~200–250 characters) appear before the "...see more" cut-off.
- **Custom Button / Link**: Custom URL on Creator Mode with custom anchor text (e.g., *"Visit my website"*, *"Book an appointment"*).
- **Profile Picture**: 400 x 400 px.
- **Banner / Background Photo**: 1584 x 396 px (Value prop, proof, CTA; keep left corner clear where avatar overlays).
- **Featured Section**: Pin 3–4 assets (Lead magnet link, viral post, video, newsletter).

---

## 3. TikTok Specifications

- **Username**: Max 24 characters.
- **Nickname / Name**: Max 30 characters (searchable).
- **Bio**: Max 80 characters (strictly enforce concise, punchy value prop + CTA).
- **Link in Bio**: Requires 1,000 followers or a verified Business Account.
- **Profile Picture / Video**: 200 x 200 px (can use 6-second looping video).
- **Pinned Videos**: Up to 3 pinned videos.

---

## 4. X (Twitter) Specifications

- **Display Name**: Max 50 characters.
- **Bio**: Max 160 characters.
- **Header Banner**: 1500 x 500 px.
- **Pinned Tweet**: 1 pinned post (Authority thread or lead magnet entry).
- **Website URL**: 1 clickable link field.
