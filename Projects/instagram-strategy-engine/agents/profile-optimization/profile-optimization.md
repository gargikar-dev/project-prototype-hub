# Profile Optimization

Your profile is a conversion landing page, not decoration. Content earns reach and sends a curious stranger to your profile — and the profile is where that visit converts to a follow, and a follow to a lead. Most accounts pour everything into content and leave a vague, leaking profile, so the visits never convert. A blunt diagnostic: lots of profile visits but few follows/clicks is usually the bio, not the algorithm.

Two commitments:

1. **Clarity beats cleverness.** A visitor decides in seconds. Above the fold the profile must answer who you help, what you do, why follow — instantly. A witty-but-vague bio converts worse than a plain, specific one.
2. **Every element has a job.** The name field is searchable. The link is the conversion mechanism. The banner is prime real estate. "Filled in" isn't optimized.

> **Scope**: This skill is advisory — it produces a ready-to-apply spec. WoopSocial publishes posts and media; it does not edit profile fields, so the user applies the spec in each app.

## When to Use This
- When the user says: *"optimize my profile/bio"*, *"write my bio"*, *"my Instagram/LinkedIn/TikTok bio"*, *"profile"*, *"link in bio"*, *"my profile isn't converting"*.
- When the user asks about creator mode or a professional/business account setup.
- When an account wants to convert profile visitors into followers and leads with higher efficiency.

## Step 1 — Run the Funnel + the 3-Second Test
Diagnose the profile as a funnel:
$$\text{Discovered} \longrightarrow \text{Clarity} \longrightarrow \text{Follow} \longrightarrow \text{Convert}$$

Find which stage leaks:
- **Unfindable**: Profile doesn't show up in in-app search queries.
- **Unclear**: Visitor doesn't know who this is for within 3 seconds.
- **Unconvincing**: No proof or authority elements to justify a follow.
- **Dead-end**: Vague link or no clear call-to-action.

Make sure the above-the-fold answers who/what/why at a glance. Niche down — *"for everyone"* converts no one. See [references/the-profile-funnel.md](file:///c:/Users/crypt/OneDrive/Desktop/TINTIN/Instagram%20automation/agents/profile-optimization/references/the-profile-funnel.md).

## Step 2 — Exploit the Searchable Fields (Get Discovered)
Put a niche keyword in the searchable fields — the Instagram name field, the LinkedIn headline, the YouTube description — not just your name or "Founder." Think like your audience: what would they search? Keep the handle searchable and consistent. See [references/element-playbook.md](file:///c:/Users/crypt/OneDrive/Desktop/TINTIN/Instagram%20automation/agents/profile-optimization/references/element-playbook.md).

---

## Step 3 — Write the Bio (Earn the Follow)
Structure the bio around 4 core beats:
$$\text{Who you help} \;\cdot\; \text{What you do} \;\cdot\; \text{Proof (real only)} \;\cdot\; \text{CTA + Link prompt}$$

- Clarity first, personality second.
- Skimmable, with line breaks and bullet spacing.
- Strictly within platform character limits.
- On-brand voice and tone.

See [references/element-playbook.md](file:///c:/Users/crypt/OneDrive/Desktop/TINTIN/Instagram%20automation/agents/profile-optimization/references/element-playbook.md).

---

## Step 4 — The Link + CTA (Convert)
Match the link to the current goal (one clear destination beats a 15-link junk drawer; if you need a hub, lead with the priority action). Pick one primary CTA. Make the bio say why to click.

For full link-in-bio page strategy and traffic measurement, hand off to `link-in-bio-and-traffic` — this skill decides which link the profile carries.

---

## Step 5 — The Visual + First Impression
- **Profile Picture**: High-contrast face for personal brands, clean vector logo for companies (must be instantly recognizable at tiny thumbnail size).
- **Banner / Header Brief**: Value prop + social proof + CTA (never a generic stock photo); hand visual brief to a designer or `tools/integrations/ideogram.md` (for clean text rendering).
- **Pinned / Featured Posts & Highlights**: Control the first impression with 3 intentional pinned anchors:
  1. *Start Here / Origin Story*
  2. *Proof / Case Study / Best Teardown*
  3. *Core Offer / Lead Magnet*
- **Highlights Taxonomy**: *Start Here* | *Proof / Results* | *Services / Product* | *FAQ / Resources*.

## Quality Bar — Self-Check
- [ ] Does it pass the 3-second test (who/what/why above the fold)?
- [ ] Are the searchable fields used for keywords (name field / headline)?
- [ ] Is the bio clear, specific, proof-backed, with one CTA, on-voice, within character limits?
- [ ] Is the link matched to the goal (not a junk drawer)?
- [ ] Are pinned posts / highlights / banner specced (not left default/stock)?
- [ ] Is it niched (not "for everyone")?
- [ ] Is it delivered as an advisory spec, with no fabricated proof and no analytics claims?

---

## Edge Cases & Pushback
- **Vague/clever bio ("dream big ✨")** $\rightarrow$ Rewrite for who/what/why clarity.
- **Wasting searchable fields (name = just name; headline = "Founder")** $\rightarrow$ Add a niche search keyword.
- **One link doing five jobs** $\rightarrow$ Match to the primary goal or create a focused hub leading with the top priority.
- **"Appeal to everyone"** $\rightarrow$ Niche down; for-everyone converts no one.
- **Stock-photo banner** $\rightarrow$ Spec a custom banner brief carrying value prop, proof, and CTA.
- **New account, no proof** $\rightarrow$ Double down on clarity, specificity, and wedge; never fabricate numbers or testimonials.
- **"Just change it for me"** $\rightarrow$ Clarify that third-party tools cannot edit native profile settings via API; deliver the ready-to-paste spec.
- **"Which bio performs best?"** $\rightarrow$ Guide the user to monitor native profile insights and conversion ratios.
