# Agent Skills: Profile Optimization

## 1. Assigned Skills & Capabilities
- **Profile Optimization Skill (`profile-optimization.md`)**:
  - *Description*: Formulates the end-to-end profile funnel (Discovered $\rightarrow$ Clarity $\rightarrow$ Follow $\rightarrow$ Convert) across bio copy, searchable name fields, CTAs, links, visuals, pinned posts, and highlights.
- **In-App Social SEO & Searchable Field Exploitation**:
  - *Description*: Researches and positions high-volume, relevant industry keywords into Instagram Name fields, LinkedIn headlines, and TikTok descriptions.
- **Conversion Bio Architecture**:
  - *Description*: Implements modular bio formulas combining target audience, value wedge, proof metrics, and single-minded call-to-action within platform character constraints.
- **Visual Grid & Highlights Curating**:
  - *Description*: Structures first-impression assets including 3 pinned posts (Authority/Origin/Offer), story highlight taxonomy (Start Here, Proof, Offer, FAQ), and header banner briefs.

## 2. Tools & MCP Integrations
- [x] Workspace File Access (Reading `brand-profile.md`, `audience.md`, and writing specs)
- [x] Image Generation / Ideogram / Flux integration briefs (Formulating visual design prompts for profile pictures, banner graphics, and story highlight covers)
- [x] Web Reader & Search (Auditing public competitor profiles and keyword trends)

## 3. Skill Execution Workflow
1. **Step 0 (Read Foundation)**: Ingest `brand-profile.md`, `audience.md`, `social-strategy.md`, and voice rules.
2. **Step 1 (Funnel Audit & 3-Second Test)**: Diagnose existing profile leaks across the 4-stage funnel (Discovered $\rightarrow$ Clarity $\rightarrow$ Follow $\rightarrow$ Convert).
3. **Step 2 (SEO & Searchable Fields)**: Optimize the Name field and handle with niche search keywords.
4. **Step 3 (Bio Synthesis)**: Write clear, high-converting bio options adhering strictly to character limits.
5. **Step 4 (CTA & Link Routing)**: Select the priority lead destination and construct compelling link-prompt copy.
6. **Step 5 (Visuals, Pinned Posts & Highlights)**: Spec the profile photo, banner design brief, 3 pinned post concepts, and highlight buckets.
7. **Step 6 (Multi-Platform Specification)**: Deliver tailored copy-paste specifications for Instagram, LinkedIn, TikTok, and YouTube.
